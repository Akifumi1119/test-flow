# TaskFlow

チームのタスクをプロジェクト単位で管理するWebアプリケーションです。

## 技術スタック

- **React 19** / **TypeScript**
- **Vite**
- **React Router DOM v7**

## 機能

### アカウント
- ユーザー登録・ログイン（JWT認証）
- プロフィール編集（名前・メールアドレス）
- アカウント削除（管理者権限を持つプロジェクトがある場合は不可）

### プロジェクト
- プロジェクトの作成・編集・削除
- プロジェクトへのメンバー追加（メールアドレスで検索、名前をチップ表示）・権限管理
- プロジェクト責任者の変更
- プロジェクトからの退場（管理者は退場不可）

### タスク
- タスクの作成・編集・削除
- タスクへのコメント投稿・編集・削除
- タスク一覧の絞り込み（ステータス・担当者・作成者）
  - 担当者フィルターは未割り当てタスクの絞り込みにも対応
- タイトルによるインクリメンタルサーチ（部分一致・候補サジェスト表示）

## セットアップ

### 1. 依存関係のインストール

```bash
npm install
```

### 2. 環境変数の設定

`.env.local` を作成して、バックエンドのURLを設定。

```env
VITE_API_BASE_URL=http://localhost:8080
```

### 3. 開発サーバーの起動

```bash
npm run dev
```

## スクリプト

| コマンド          | 内容                   |
| ----------------- | ---------------------- |
| `npm run dev`     | 開発サーバー起動       |
| `npm run build`   | 本番ビルド             |
| `npm run preview` | ビルド結果のプレビュー |
| `npm run lint`    | ESLintによる静的解析   |

## ディレクトリ構成

```
src/
├── components/   # 共通UIコンポーネント（Header・ErrorMessage・Spinner・PasswordInput）
├── layouts/      # ページレイアウト（AppLayout）
├── pages/        # 各ページコンポーネント
└── utils/        # API設定・日付フォーマットなどのユーティリティ
```

## デプロイ

Vercelにホスティング。`vercel.json` でSPA向けのリライト設定済み。バックエンドはRender（`https://test-flow-backend.onrender.com`）にデプロイしています。
